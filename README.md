# 🛒 Desafío E-Commerce

Proyecto de comercio electrónico desarrollado con Next.js (Pages Router), TypeScript y Tailwind CSS, simulando un flujo completo de compra al estilo Mercado Libre / Mercado Pago.

---

## 🚀 Tecnologías Utilizadas

* **Framework:** Next.js 16 (Pages Router)
* **Estilos:** Tailwind CSS v4
* **Tipado:** TypeScript
* **Despliegue:** Vercel

---

## ✨ Características Principales

* **Búsqueda de productos:** Consulta dinámica de artículos en tiempo real.
* **Detalle de producto:** Visualización de información detallada, precios y botón de compra directa.
* **Flujo de Checkout:** Proceso de pago integrado para la orden de compra.
* **Autenticación de usuarios:** Sistema de ingreso y perfil de usuario.
